
	Video Metadata Provider

This sample demonstrates how to develop a metadata player for AppVision.
Metadata provider offers the ability to draw shapes, texts or images over a video player.
A common use case is to display video analytics overlays such as detection bounding boxes.

This sample project uses the YOLO Neural Networks for object detection (see https://github.com/AlexeyAB/darknet)

PlayerMetadata class implements the IPlayerOverlay interface.
