
	Demo Overlay Manager

This C# project references 'appCommon.dll', 'appData.dll', 'appSDK.dll'
The output 'OverlayManager.exe' is copied into 'AppVision 4\Bin\' folder.

This manager allow to create/update/delete overlays.
This functionality as since been integrated in the Client, it is available at Menu -> Administration -> Overlays
