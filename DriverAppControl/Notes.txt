---------------------------------------------------
Notes on the download
---------------------------------------------------
The methods that download data to a controller are in the Device class:
	. Download
	. DownloadHolidays
	. DownloadTimetables
	. DownloadProfiles
	. DownloadUsers

The classes that model the data downloaded to a controller are:
	. DeviceTimetable:	timetable
	. DeviceProfile:	access profile
	. DeviceUser:		person (one entry per badge)

The downloaded data is re-indexed (a controller does not use the ids of the Param or AppControl
databases). The DeviceIndex class keeps the link between both ids:
	. timetables: the indexes are saved in the file {name}_TID.xml
	. users: the indexes are saved in the file {name}_UID.xml
	. access profiles are not re-indexed, they are built dynamically;
	  their content is saved in the file {name}_P.xml
The files are written in the Param folder of the configuration (current directory of the driver).

Warning: a person with several badges has several DeviceIndex entries with the same AppId.
