
	Custom MapProvider for AppVision

This sample project demonstrates how to build a custom GIS map provider for AppVision.
It uses Microsoft® Bing Maps as its data source.

Note: Bing Maps APIs require a key. To get your Bing Maps Key, go to
https://docs.microsoft.com/en-us/bingmaps/getting-started/bing-maps-dev-center-help/getting-a-bing-maps-key
